## 📌 About

This repository serves as my personal log of Data Structures & Algorithms practice. Every time I solve a problem on LeetCode, the **LeetSync** extension automatically pushes my accepted solution here — no manual copy-pasting involved.

The goal is simple: build consistency, track progress, and have a searchable archive of solved problems for revision before interviews.


## 📂 Repository Structure

Each solved problem gets its own folder, named after the problem, containing the solution and a short problem description:

```
LeetCode/
├── 1-two-sum/
│   ├── two-sum.cpp
│   └── README.md
├── 2-add-two-numbers/

└── README.md   ← you are here
```
